# Cerium-Turbo

Воксельная танковая игра на **Rust** (`Bevy 0.20` + `Avian3D 0.8` + `block-mesh`), вдохновлённая *World of Tanks* и *War Thunder*.

- **Веб-версия (GitHub Pages):** https://sanzharshaymerdenov5-collab.github.io/Cerium-Turbo/
- **Правило AP-Only:** на этапах 1–6 в игре присутствует **только сплошной бронебойный снаряд (`SolidAP`)**. Остальные типы снарядов (каморные, фугасные, кумулятивные, подкалиберные) добавляются только после завершения Этапа 6.

## Этапы разработки

- [x] **Этап 1:** Рабочий прототип — 1 танк (**Т-34-85**), 1 карта (**«Полигон»**), без врагов (ангар, гусеничная физика с 8-точечной пружинной подвеской, баллистика сплошного снаряда AP, разрушаемые постройки и неразрушаемый рельеф, мишени 50/150/250 м).
- [x] **Этап 2:** ИИ-враги (`VoxelNavGrid` + A* обход с пересчётом при разрушении стен, баллистическое упреждение сплошным `SolidAP`, ромбование, 3D-броня, победа/поражение, исправлен разворот при движении вперёд `W+A/D`).
- [x] **Этап 3:** Система повреждений по ХП (`ArcadeHpAndModules`: общее ХП танка + ХП и состояния 7 модулей, подрыв БК, пожар баков, расходники `[5]`/`[6]`, зелёный/жёлтый/красный индикатор пробития, кукла модулей).
- [x] **Этап 4:** Увеличение парка до 5 танков (**Т-34-85**, **M24 Chaffee**, **Pz.Kpfw. VI Tiger I**, **СУ-100**, **ИС-3**) с уникальными процедурными силуэтами, бронесхемами и 3D-рентгеном брони/модулей в ангаре.
- [x] **Этап 5:** Расширение до 5 карт (**Полигон**, **Разрушенный город**, **Пустынный каньон**, **Зимний укрепрайон** со льдом, **Промзона / ЖД узел**), выбор локации в ангаре и плавная дозированная перестройка разрушенных чанков.
- [x] **Этап 6:** Модульная система повреждений без общего ХП (`ModulesOnlyWt`, стиль *War Thunder*: остаточное пробитие `SolidAP`, 3D-конус осколков `Spall Cone`, 3D-рассадка и 7-сек пересадка 4 членов экипажа, гибель при `< 2` танкистах или подрыве БК, окно **WT X-Ray Hit-Cam**) + переключатель режимов **`[M]`** (`WoT` / `War Thunder`) и встроенный кириллический шрифт `DejaVuSansMono` для WASM/Pages.
- [x] **Визуал техники (после Этапа 6):** Повышенная детализация всех 5 танков — шаг вокселей `0.08` м (`0.04` м на стволе), вершинный **Ambient Occlusion** ([`mesh_grid_ao`](file:///home/antigravity/sanzharshaymerdenov5-collab/Cerium-Turbo/src/voxel/mesher.rs#L185-L282)), уникальные ходовые (катки Кристи с перфорацией у Т-34-85/СУ-100, ролики у M24/ИС-3, 8 шахматных катков у Tiger I), башенки с оптикой, маски орудий, двухкамерные дульные тормоза, полые стволы, топливные баки, глушители Фейфеля, бревно самовытаскивания и камуфляж противников.

> **Этапы 1–6 завершены!** Правило **AP-Only (`ShellType::SolidAP`)** выдержано на всех этапах. Далее можно открывать разработку альтернативных снарядов (`APHE`, `HE`, `HEAT`, `APCR/APDS`), новой техники, карт и `.vox`-моделей.

## Управление

| Клавиша | Действие |
|---|---|
| `1`–`5` / `←` `→` (в ангаре) | Выбор танка |
| `Q` / `E` (в ангаре) | Выбор карты |
| `M` / Кнопка (в ангаре) | Переключение режима урона: `WoT (ХП + Модули)` / `War Thunder (Только модули)` |
| `V` (в ангаре) | Рентген 3D-брони, модулей и экипажа |
| `Мышь` + колёсико (в ангаре) | Осмотр танка на подиуме |
| `Enter` / `Пробел` / Кнопка | Выход в бой из ангара |
| `W` / `S` | Газ / задний ход |
| `A` / `D` | Разворот гусеницами (включая на ходу `W+A/D`) |
| `Мышь` | Вращение камеры и наведение башни/орудия |
| `ЛКМ` / `Пробел` | Выстрел (сплошной AP) |
| `Shift` | Снайперский прицел |
| `5` / `6` | Ремкомплект / Огнетушитель |
| `R` | Поставить танк на гусеницы |
| `Tab` | Вернуться в ангар |
| `Esc` | Освободить курсор мыши |

## Локальный запуск

```bash
cargo test --lib
cargo run --release
```
